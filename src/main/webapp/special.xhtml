Специальные операции

Каждая операция выполняется функцией базы данных, которую вызывает уровень бизнес-логики.

1. Фильм с минимальными сборами в США

Возвращает один (любой) фильм с минимальным usaBoxOffice. Функция БД get_movie_with_min_usa_box_office.

, usaBoxOffice = Фильмов пока нет.

2. Количество фильмов со сборами в США больше заданных

Функция БД count_movies_with_usa_box_office_greater.

Количество фильмов: #{specialOperations.usaCount}

3. Фильмы, слоган которых содержит подстроку

Поиск подстроки в tagline с учётом регистра; фильмы без слогана в результат не попадают. Функция БД find_movies_by_tagline_substring.

#{m.name} #{m.tagline} #{empty m.genre ? 'null' : m.genre} #{empty m.director ? 'null' : m.director.name}

4. Сценаристы без «Оскаров»

Сценаристы, ни один фильм которых не получил ни одного «Оскара». Функция БД find_screenwriters_without_oscars.

#{p.id} #{p.name} #{p.passportID}

5. «Оскары» режиссёров жанра

Находит все фильмы режиссёров, снявших хотя бы один фильм в выбранном жанре, и выводит их «Оскары». Функция БД find_oscars_of_directors_by_genre.

Фильмов: #{specialOperations.oscarMovies.size()}, «Оскаров» всего: #{specialOperations.oscarsTotal} #{m.name} #{m.director.name} #{empty m.genre ? 'null' : m.genre} #{m.oscarsCount}
